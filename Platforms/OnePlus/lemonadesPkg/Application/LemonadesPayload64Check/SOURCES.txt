C syntax/type/ZeroMem/CopyMem adaptation only. This checksum diagnostic does
not implement a signature trust policy. Host tests compare the exact source
against hashlib including padding boundaries and the full 64 MiB image.

The application is external on FAT32, never in the firmware FV. It reads
every block of the 64 MiB volume, a complete 60 MiB fixture, checks SHA256
and EOF, and checks seeks across 16 MiB, 32 MiB and file end. No persistent
write or XNU entry is performed. Whole-volume digest is verified by host
against the archived image; file digest is checked inside the application.
